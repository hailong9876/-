# 自动连点器

这是一个简洁的 Windows 自动连点器，支持：

- F6：开始/停止连点
- F7：退出程序
- 可在界面中设置点击间隔（秒）
- 可直接打包成 `.exe` 可执行程序

## 运行方式

1. 安装依赖：

```bash
python -m pip install -r requirements.txt
```

2. 运行脚本：

```bash
python clicker.py
```

3. 使用方法：
   - 点击“开始”按钮，或按 `F6`
   - 点击“停止”按钮，或按 `F6`
   - 按 `F7` 退出程序

## 打包成 EXE

在 Windows 命令提示符中执行：

```bat
build_exe.bat
```

生成的文件会在 `dist/AutoClicker.exe`。

## 注意事项

- 该脚本会在当前鼠标位置点击，适合点击游戏、网页、桌面自动化场景。
- 如需减少误触，建议在程序运行时不要移动鼠标到屏幕角落，或者调低 `FAILSAFE` 相关设置。
- 打包成功后，程序默认以窗口模式运行，便于控制与关闭。
